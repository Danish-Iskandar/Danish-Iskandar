## 🚀 Featured Project

### 🏗️ Adaptive VR Training System for Quay Crane Operators *(Final Year Project)*

A VR training environment that adapts to trainees in real time by detecting their emotional state from voice.

- **Speech Emotion Recognition** using a **CNN-LSTM** model trained on RAVDESS, IEMOCAP and SAVEE, classifying four emotion classes
- **Five-layer architecture:** audio capture → CNN-LSTM SER → Socket.io / WebSocket middleware → Unity avatar output → instructor dashboard
- Color-state avatar feedback so trainees and instructors get clear, low-latency emotional cues
- Instructor dashboard for monitoring trainee state during sessions

`Python` `Deep Learning` `Unity` `WebSockets` `Socket.io`
